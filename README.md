## Intro

Practice implementing Lodash methods with the official documentation, examples, and test suite in one place.
The challenges follow Lodash `4.18.1`; solutions run in a browser worker, and completed challenges are saved locally in your browser.

## Play

1. Choose a Lodash method from the sidebar.
2. Read the documentation and examples.
3. Implement the method in the editor.
4. Run the examples, then check the official tests.
